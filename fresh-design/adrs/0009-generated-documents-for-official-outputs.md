# ADR-0009: Generated documents for official outputs

Author: Tinashe K

## Status

Accepted

## Context

The legacy application generated many PDF and Excel outputs. The new eMhare must support official outputs such as offer letters, result slips, transcripts, certificates, statements, and other student records.

Browser print output is not enough for official records because it is hard to audit, reproduce, store, and control.

## Decision

Official outputs shall be generated as stored generated documents.

Offer letters, result slips, transcripts, certificates, statements, and other official academic/finance outputs shall be generated through the Documents/Reporting service and stored with metadata.

## Consequences

- Official documents can be previewed, downloaded, audited, and regenerated according to policy.
- Published official documents are not overwritten.
- Corrections require amendment, reversal, superseding document, or regenerated version history.

## Implementation Notes

- Generated documents must store template, input parameters, owner, generated by, generated at, storage key, checksum, and publication status.
- Offer letters in Release 1 use this mechanism.
- Future result slips, transcripts, and certificates use the same mechanism.
